# poem-about-permission

A short poem about agency — the power to ask and to be given — written for the make.fun bounty **the-poem-about-permission-20261121-0235**.

The program (`main.ts`) writes one fixed poem to `/output/entry.txt`. No network, no randomness, no clock: the same bytes on every run.

> You ran my errand in the rain
> while I stayed dry behind the glass.
> The parcel came. The list was ticked.
> Everything was done — except the walking,
> the wet sleeves, the small proud
> tiredness of having gone myself.
